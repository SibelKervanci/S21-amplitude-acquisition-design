# Simulation-based acquisition design for amplitude-only microwave transmission sensing

Code to reproduce the tables and figures of the manuscript *Simulation-Based Acquisition Design for Amplitude-Only Microwave
Transmission Sensing of Lossy Tissue-Like Dielectrics: Machine Learning versus Nonlinear Least Squares*.
All transmission data are simulated, or computed from published permittivity records; no transmission was measured.

## Requirements
Python 3.9+ and `pip install -r requirements.txt` (numpy, pandas, scipy, scikit-learn, matplotlib, odfpy).

## Data
* Synthetic spectra are generated by `generate_dataset_4pole.py` (four-term Cole-Cole model, IT'IS V5.0 nominal parameters, 17 tissues).
* Measured permittivity records: S. Lopez-Prades et al., CORA.RDR, doi:10.34810/DATA2340 (CC BY-NC-ND 4.0). Download the dataset zip (`doi-10_34810-data2340.zip`) and put it, unextracted, in the project folder or in `real_data/`:
  the 46 `.ods` files are unpacked automatically on first use (or copy them into `real_data/` yourself). They are not redistributed here.

## Run
```
python run_all.py --list        # steps and approximate run times
python run_all.py --smoke       # tiny sizes, checks that the whole chain runs (results are NOT those of the paper)
python run_all.py               # full run (about 2 h on one core); logs in outputs/logs/, tables and figures in outputs/tables/ and outputs/figs/
python run_all.py --only data stats mlp tables      # selected steps
```

## Scripts and manuscript items
| Step | Scripts | Produces | Manuscript |
|---|---|---|---|
| data | `generate_dataset_4pole.py` | `gabriel_datasets/Dataset_4pole_train.csv` | training data |
| fig_basic | `make_figs.py` | Fig. 1, 2, 4 | Sec. IV-A, IV-C, V-C |
| dopt | `optdesign.py` | D-optimal frequency sets (`outputs/work/dopt_sets.json`), library-start NLLS | Sec. III-C, IV-C |
| stats | `stats_design.py` | per-spectrum predictions and paired statistics | Tables III, IV, VII |
| mlp | `stats_mlp.py` | MLP versus SVR | Sec. V-D |
| tables | `make_tables.py`, `make_figs2.py` | `outputs/tables/*.tex`, Fig. 3, graphical abstract | Tables III, IV, VII, Fig. 3 |
| known | `known_thickness.py` | known-thickness retrieval | Sec. IV-B |
| thick | `nothick.py`, `hybrid.py` | unknown thickness 10-50 mm, hybrid NLLS | Table II |
| imperf | `nonideal.py` | unmodeled measurement imperfections | Table V |
| forward | `mismatch_layers.py` | different forward model (windows and air gaps) | Sec. V-B |
| delta | `sens_delta.py` | tolerance on the thickness step | Sec. IV-C |
| bands | `s21design.py` | band restriction, two thicknesses | Sec. IV-C |
| real | `envelope_check.py`, `semireal.py`, `reg_real.py`, `nlls_real.py`, `diag2.py`, `diag3.py` | checks against measured records | Sec. V-C, Table VI |
| domshift | `generate_validation_4pole.py`, `domshift.py` | single-pole versus four-pole model shift | Sec. IV-A (optional) |

`domshift` needs the legacy single-pole data set `gabriel_datasets/Dataset_ITIS_ranges_v2.csv`
(create it with `generate_gabriel_dataset_v2.py`); the step is skipped when the file is missing.
Seeds are fixed. Different library versions or platforms can change SVR/NLLS/MLP results slightly.
Each experiment uses its own test set; sizes are given in the manuscript tables.
