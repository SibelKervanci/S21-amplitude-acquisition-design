# Reference outputs
Logs (`*.log`) and `stats.json` from one complete run of `python run_all.py` on the authors' machine
(Windows, Anaconda env with Python 3, scikit-learn, SciPy; single run, fixed seeds). All numbers in the paper
come from this run. Console messages in the logs are in Turkish; numbers are what matter.
Small differences (a few tenths of a percentage point) can occur with other library versions or CPUs.
Saved predictions (`preds.npz`) are not included (large); `run_all.py` regenerates them.
